# ZoneBar Implementation Plan

> **For agentic workers:** Use superpowers:executing-plans to implement this plan task-by-task.

**Goal:** 原生多时区菜单栏时钟。
**Architecture:** ClockCore 负责数据、校验和格式化；ZoneBar 负责状态栏、设置和持久化。
**Tech Stack:** Swift 5.9、AppKit、SwiftUI、XCTest。
**Spec:** docs/superpowers/specs/2026-11-08-zonebar-design.md

## Global Constraints
macOS 13+；无第三方依赖；不修改系统时区或时间；多个时区并排显示。

## Review Focus
夏令时切换、跨日、无效/重复时区、空格式/过长名称、设置恢复与最后一个时区删除。

### Task 1: Core
- [x] 写 XCTest：相同瞬间跨日、洛杉矶夏令时边界、12 小时/自定义格式、持久化往返和数据恢复。

- [x] 创建 Sources/ClockCore/ClockSettings.swift：Codable 设置和 zone model；normalized() 校验；formatter(for:) 构造指定时区的 DateFormatter；title(at:) 按配置顺序拼接。
- [x] swift test 通过。
