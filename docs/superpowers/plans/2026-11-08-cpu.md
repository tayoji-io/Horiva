## 最终结果与用户追加范围
- 首轮缓存优化后设置窗口打开时 20 秒平均 2.75%，未达到预期；继续采样确认剩余 SwiftUI 预览布局开销。
- 将实时预览改为原生 NSTextField 容器，按需更新文本，不驱动整个 SwiftUI 设置页面排版。
- 用户明确允许不使用自定义下拉菜单，并要求移除菜单时间预览：现仅保留普通系统菜单动作项，无 hosted SwiftUI 菜单视图或外部点击监听。
- 状态栏从 attributedTitle 改成普通 title，悬停说明仅在配置变化时更新。
- 最终开启秒、仅状态栏运行的两次 20 秒采样分别为 2.25% 和 2.95%。sample 显示热点转为 AppKit NSStatusItem replicant 快照/重绘，不能宣称秒模式已接近零占用。
- 分钟格式、设置窗口打开的 20 秒采样为 0.15%。原来的 MM/dd EEE HH:mm:ss 已在 UI 中恢复并确认实时生效。
- 14 项 XCTest 通过；release 构建与本机签名完成。参数验证和缓存更新测试保存在 ClockSettingsTests.swift，复现 CPU 采样脚本保存在 scripts/measure_cpu.py。
