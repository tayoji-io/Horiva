# ZoneBar
用户选择 A：多个时区直接并排显示在菜单栏。新增独立时钟，不修改系统时区或时间，也不尝试替换受系统管理的时钟。

原生 Swift + AppKit 状态栏，SwiftUI 设置窗口，macOS 13+，无第三方依赖。另一方案为菜单栏只显示主时区，用户选择了更直观的并排显示。

默认上海、洛杉矶。可搜索 IANA 时区、添加/删除/排序、编辑显示名称。至少保留一个时区。预设 12/24 小时、秒、日期与自定义 Unicode 日期格式；显示即时预览。使用 Foundation TimeZone 自动处理夏令时。设置保存到应用自己的 UserDefaults。关闭窗口仍在菜单栏运行，菜单可退出。生成本机可运行的 app 和 zip，不自动开机启动。
